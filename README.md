# Forage Virtual Internship - PWC

## 📌 Overview
This repository contains Power BI reports and dashboards developed as part of the **Forage Virtual Internship Program** offered by **PWC**. The project involved real-world data analysis tasks, focusing on **data cleaning, visualization, and business insights generation**.

## 🛠️ Tools Used
- **Power BI** - Data visualization and dashboard creation
- **SQL** - Data extraction and transformation
- **Excel** - Data preprocessing and validation
- **DAX (Data Analysis Expressions)** - Advanced calculations and measures

## 📂 Files in this Repository
| File Name       | Description |
|----------------|------------|
| `Report1.pbix` | Sales analysis dashboard |
| `Report2.pbix` | Customer segmentation insights |
| `Report3.pbix` | Financial performance overview |

## 📊 Project Highlights
- **Data Integration:** Combined datasets from multiple sources to create a **cohesive data model**.
- **Interactive Dashboards:** Developed Power BI reports with **drill-through features, slicers, and KPIs**.
- **Data Insights:** Identified key trends such as **revenue growth, customer behavior, and operational efficiency**.

## 🚀 How to Use
1. Download the `.pbix` files.
2. Open them in **Power BI Desktop**.
3. Explore the interactive reports and insights.
